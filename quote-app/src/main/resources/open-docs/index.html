报价 API 开发者文档

版本 v1 · 中文 · 示例行情（测试环境的价格来自模拟报价源，不是真实市场价格）

报价服务对外提供 REST 和 WebSocket 两种接口，和平台自己的交易应用用的是同一套报价、同一套 WebSocket 协议。价格是报价商整合后的原始买卖价，不含任何点差加价。

第一版只计量、不收费：没有账单和在线支付。Key 由平台运营在后台建好后交给你，没有自助注册。

1. 鉴权（签名）

每个 Key 有一个 Key ID（qk_ 开头）和一个 Secret（qs_ 开头）。Secret 只在建 Key 时给你一次，请妥善保存；丢了只能让运营"轮换"出一个新 Key（旧 Key 立即停用）。

每个 REST 请求带四个请求头：

请求头类型说明
X-QK-Key字符串Key ID
X-QK-Timestamp整数（秒）当前 Unix 时间戳（秒），和服务器时间相差不能超过 300 秒
X-QK-Nonce字符串每个请求一个新的随机串（8～64 位字母、数字、-、_）；同一个 Key 10 分钟内用过的 nonce 再用会被拒（防重放）
X-QK-Signature字符串HMAC-SHA256(Secret, 签名原文)，小写十六进制

签名原文 = 时间戳 + "\n" + nonce + "\n" + 方法 + "\n" + 路径（带 ? 和查询串，和请求里一模一样）+ "\n" + 请求体；GET 请求的请求体是空字符串。路径里不能有 ;、% 编码、..（返回 400）。

// Node.js 示例
import crypto from 'node:crypto';
const base = 'https://报价服务地址';          // 测试环境地址由运营告诉你
const keyId = process.env.QK_KEY, secret = process.env.QK_SECRET;
async function call(method, pathWithQuery, body = '') {
  const ts = String(Math.floor(Date.now() / 1000));
  const nonce = crypto.randomUUID().replaceAll('-', '');
  const sig = crypto.createHmac('sha256', secret).update(`${ts}\n${nonce}\n${method}\n${pathWithQuery}\n${body}`).digest('hex');
  const r = await fetch(base + pathWithQuery, { method, body: body || undefined,
    headers: { 'X-QK-Key': keyId, 'X-QK-Timestamp': ts, 'X-QK-Nonce': nonce, 'X-QK-Signature': sig } });
  return [r.status, await r.json()];
}
console.log(await call('GET', '/v1/quotes?symbols=EURUSD,XAUUSD'));
# Python 示例
import hashlib, hmac, os, time, urllib.request, json, uuid
def call(method, path, body=''):
    ts = str(int(time.time()))
    nonce = uuid.uuid4().hex
    sig = hmac.new(os.environ['QK_SECRET'].encode(), f'{ts}\n{nonce}\n{method}\n{path}\n{body}'.encode(), hashlib.sha256).hexdigest()
    req = urllib.request.Request(os.environ['QK_BASE'] + path, method=method, data=body.encode() or None,
                                 headers={'X-QK-Key': os.environ['QK_KEY'], 'X-QK-Timestamp': ts, 'X-QK-Nonce': nonce, 'X-QK-Signature': sig})
    return json.load(urllib.request.urlopen(req))
print(call('GET', '/v1/symbols'))

2. 错误和限额

出错时返回统一格式，每个响应头都有 X-Trace-Id（和 traceId 一样），联系运营时请带上。

字段类型说明
code字符串错误码，见下表
message字符串中文说明
traceId字符串追踪号
HTTPcode什么时候
401UNAUTHORIZEDKey 不存在、已停用、签名不对、时间戳超出 ±300 秒、nonce 用过了
400BAD_PATH路径里有 ;、% 编码、.. 等
503SERVICE_UNAVAILABLE服务暂时不可用，按 Retry-After 稍后重试
403OPEN_SERVICE_CLOSED报价对外服务还没有开放（外部 Key 暂时不能用）
429RATE_LIMITED超过每秒或每天请求数限额；响应头 Retry-After（秒）。另带 scope（second / day）、limit、remaining（0）、resetAt（毫秒）
400SYMBOLS_REQUIRED、TOO_MANY_SYMBOLS、TIMEFRAME_INVALID、SYMBOL_NOT_AVAILABLE参数不对；或这个 Key 拿不到这个品种

默认限额（每个 Key 可以单独调整，用 用量接口 查看自己的）：REST 每秒 10 次、每天 10 万次（UTC 0 点重置）；WebSocket 同时 2 条连接、每条最多订阅 50 个品种。超了只拒超出的那部分，已订阅的照常推送。被拒的请求不算进请求数。

3. 状态

status含义有没有价格
OPEN开市，正常报价有
DEVIATION两家报价商价格偏差过大，照常给主报价商的价格有
CLOSED休市没有
NO_QUOTE暂无报价（报价源中断、报价过期，或这个品种暂时不能对外提供）没有

4. REST · 品种列表 GET /v1/symbols

返回这个 Key 现在能拿到的品种：{"items": [...]}，每项：

字段类型说明
code字符串品种代码，例如 EURUSD
nameZh字符串中文名
nameEn字符串英文名
category字符串类别：fx 外汇 / metal 贵金属 / index 指数 / energy 能源 / crypto 加密货币 / stock 美股
digits整数价格小数位
sessions数组每周交易时段（UTC），每项 {"day": 1～7（周一～周日）, "open": "22:00", "close": "24:00"}，含开始、不含结束
status字符串见第 3 节

5. REST · 最新报价 GET /v1/quotes?symbols=EURUSD,XAUUSD

symbols 必填，逗号分隔，一次最多 50 个。返回 {"items": [...], "unavailable": [拿不到的品种]}，每项：

字段类型说明
symbol字符串品种代码
bid字符串（数字）买价（你卖出的价格）；休市、暂无报价时没有这个字段
ask字符串（数字）卖价（你买入的价格）；休市、暂无报价时没有这个字段
time整数（毫秒）报价时间，Unix 毫秒；还没有报价时为 null
status字符串见第 3 节

6. REST · K 线 GET /v1/klines?symbol=XAUUSD&tf=15m&limit=300

参数：symbol（必填）、tf（必填：1m、5m、15m、1h、4h、1d）、from、to（可选，UTC 秒，含两头）、limit（默认 300，最多 1,000）。K 线按买卖中间价算。返回 {"symbol", "tf", "items": [...]}，从旧到新，每项：

字段类型说明
time整数（秒）这根 K 线的开始时间，UTC 秒
open字符串（数字）开盘价
high字符串（数字）最高价
low字符串（数字）最低价
close字符串（数字）收盘价（最后一根未收盘时是最新价）

7. REST · 用量 GET /v1/usage

这个 Key 的限额、今天和最近 30 天的用量（按 UTC 日）。返回 {"limits": {...}, "today": {...}, "days": [...]}。

字段（limits）类型说明
restPerSecond整数REST 每秒请求数
restPerDay整数REST 每天请求数
wsConnections整数WebSocket 同时连接数
wsSymbolsPerConnection整数每条连接最多订阅品种数
字段（today、days 的每项）类型说明
date字符串日期（UTC），例如 2026-11-17
restRequests整数REST 请求数（不含被拒的）
restRejected整数因超限被拒（429）的请求数
wsPushes整数WebSocket 推送条数（报价和 K 线，不含心跳）
wsConnectionSeconds整数（秒）WebSocket 连接时长合计
wsPeakConnections整数当天同时连接数峰值

today 另有 wsConnectionsNow（整数，现在的连接数）。

8. WebSocket

8.1 连接

先用签名的 REST 换一张连接票据（5 分钟有效、只能用一次，浏览器里不用放 Secret），再连 WebSocket：

POST /v1/ws-ticket（请求体为空）→

字段类型说明
ticket字符串票据
expiresAt整数（毫秒）过期时间
path字符串连接路径 /v1/ws?ticket=…（把 https 换成 wss）

握手被拒：票据无效或 Key 已停用 → 401；对外服务还没有开放 → 403；已有"连接数限额"那么多条连接 → 429（已有的连接不受影响）。

连接被服务器关闭时的关闭码：4401 Key 已停用或已轮换（停用后 5 秒内）；4403 对外服务已关闭。其他情况（网络中断、服务器重启）请 1 秒起每次翻倍、最长 60 秒地重连，重连后重新换票据、重新订阅。

8.2 你发的消息

{"op": "subscribe", "symbols": ["EURUSD", "XAUUSD"], "epoch": "上次 hello 的 epoch（可选）", "since": {"EURUSD": 1234}}
{"op": "watchBars", "keys": ["XAUUSD|15m"]}
{"op": "resync", "symbols": {"EURUSD": 1234}}
  • subscribe：整份替换要的品种（退订 = 发一份更小的列表，空列表 = 全部退订）。超过每条连接的品种数 → 回 error SUBSCRIBE_LIMIT，这次不生效、已订阅的照常推；拿不到的品种回 error SYMBOL_NOT_AVAILABLE（带 symbols），其余照常订阅。带上次的 epoch 和每个品种最后收到的 seq，服务器从下一条开始补齐，补不上就发快照。
  • watchBars：整份替换要推 K 线变化的"品种|周期"（品种要先订阅）。
  • resync：发现某个品种的 seq 跳号时要求补齐（值写最后连续收到的序号，-1 = 直接要快照）。

8.3 服务器发的消息

hello（连上后的第一条）类型说明
type字符串"hello"
epoch字符串报价服务这次启动的编号；变了说明重启过，序号重新从 1 开始，丢掉旧序号
serverTime整数（毫秒）服务器时间
subscribed（订阅生效）类型说明
type字符串"subscribed"
symbols数组现在订阅着的品种
quote（报价）类型说明
type字符串"quote"
symbol字符串品种代码
seq整数这个品种的序号，同一个 epoch 里只增不减；暂时不能对外提供的报价会跳过，所以可能跳号
bid字符串（数字）买价；休市、暂无报价时没有
ask字符串（数字）卖价；休市、暂无报价时没有
time整数（毫秒）报价时间
status字符串见第 3 节
snapshot布尔只在快照时出现（true）：以这条为新的起点
bar（K 线变化）类型说明
type字符串"bar"
symbol字符串品种代码
tf字符串周期
time整数（秒）这根 K 线的开始时间
open字符串（数字）开盘价
high字符串（数字）最高价
low字符串（数字）最低价
close字符串（数字）最新价
heartbeat（每秒一条）类型说明
type字符串"heartbeat"
serverTime整数（毫秒）服务器时间；超过 10 秒没收到任何消息请断开重连
error类型说明
type字符串"error"
code字符串BAD_MESSAGE、SUBSCRIBE_LIMIT、SYMBOL_NOT_AVAILABLE
message字符串中文说明
symbols数组只在 SYMBOL_NOT_AVAILABLE 时出现：拿不到的品种
// 浏览器 / Node 22 示例：先在你的服务器上用签名换票据，再把 path 交给前端
const [, t] = await call('POST', '/v1/ws-ticket');
const ws = new WebSocket(base.replace(/^http/, 'ws') + t.path);
ws.onmessage = (e) => {
  const m = JSON.parse(e.data);
  if (m.type === 'hello') ws.send(JSON.stringify({ op: 'subscribe', symbols: ['EURUSD', 'XAUUSD'] }));
  if (m.type === 'quote') console.log(m.symbol, m.status, m.bid, m.ask);
};
